UI Rules



Every screen answers:



What happened?



Why?



What should I do next?



No useless metrics.



No decorative cards.



Every card has purpose.



Every icon has meaning.



Every color communicates state.



Animations only when improving understanding.



Spacing must be intentional.



Typography first.



Content before decoration.
